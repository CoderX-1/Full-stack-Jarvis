# fullstack-agent: provider-neutral installer

This repository is an AI-operated installer. When the user asks to set it up,
read `fullstack-agent.md` completely and follow it. The supported brains are
OpenAI, Gemini through Google's OpenAI-compatible endpoint, and custom
OpenAI-compatible APIs. Never require Claude or an Anthropic account.

If setup already exists in the parent folder, offer to start, update, repair,
or add a skipped component. Work from the parent folder for everyday agent
sessions. Never delete, overwrite, or move anything the user built, and ask
only one setup question at a time.
